# 测试范围

自动回归测试覆盖：

- 标准键、左右修饰键、主键区和数字键盘归一化；
- F13–F24、媒体键和未知键；
- 长按去重、组合键、多键盘和设备移除；
- Alt+Tab 补偿与重复计数保护；
- 鼠标左右键、暂停和本次清零；
- 稀疏计数编码兼容性；
- SQLite 分钟写入、绝对快照和跨重启累计；
- 全部范围边界、十分钟汇总和时段序列；
- 历史总数量；
- CSV 导出和设置文件；
- PrtSc 的假 Shift 事件不会被误计为 Shift；
- Raw Input 缺少按下事件时由轮询兜底补计；
- Raw Input 与轮询两个来源不会重复计数（两种到达顺序都覆盖）；
- 丢失松开事件后由物理状态复核自愈并重新计数；
- NumLock 关闭时小键盘与导航键别名不会重复计数；
- 轮询映射覆盖全部键位并区分左右修饰键。

发行前还应在 Windows 10/11 手动验证托盘、登录自启动、窗口隐藏、完整退出、不同时间范围及 DPI 缩放；
另外建议实测 PrtSc 与被其它程序热键占用的组合键（如翻译工具的 Shift+Z），确认“采集健康度”里的
“轮询兜底”计数会随之增加。
