# KeyStats V1.0

KeyStats 用于统计键盘按键以及鼠标左右键的使用次数。所有数据只保存在本机，不登录、不上传，也不记录输入内容、输入顺序、使用中的应用或鼠标位置。

## 基本使用

- 运行 `KeyStats.exe` 后即可开始采集；
- 关闭主窗口后程序会继续在系统托盘运行；
- 双击托盘图标可以重新打开统计窗口；
- **需要停止采集时，请点主窗口里的「退出 KeyStats」，或从托盘菜单选择“完整退出”**；
- Windows 11 默认把新程序的托盘图标收进任务栏的 `^` 溢出区，可以在那里找到 KeyStats；
- “暂停采集”不会删除已有记录；
- “清零本次显示”只影响本次运行，不删除历史数据。

## 登录后自动启动

- 勾选“登录 Windows 后自动启动”后，程序会以当前绿色版路径静默启动（托盘运行）；
- 如果这台机器禁止写入注册表启动项（安全软件或组策略），程序会**自动改用「启动」文件夹里的快捷方式**，
  并在界面上说明“已改用「启动」文件夹”，无需你手动处理；
- 如果曾经把程序移动到别的位置，界面会提示“检测到指向旧位置的启动项”，点旁边的
  **“更新自启动位置”** 即可修正；
- 两种方式都失败时，按提示把 KeyStats 的快捷方式手动放进「启动」文件夹即可
  （`Win+R` 输入 `shell:startup` 可直接打开该文件夹）。

## 时间与热力图

- 支持今天、最近 10 分钟、最近 7 天、最近 30 天、全部和自定义范围；
- 自定义范围可以按 10 分钟向外对齐，也可以精确到整分钟；
- 时段热力图按一天中的 144 个十分钟时段汇总；
- 鼠标停在时段热力图上约 0.5 秒后，会显示具体时间段和输入次数；
- “总数量”表示数据库中的全部历史输入加上当前尚未自动保存的输入。

## 采集健康度

主窗口右侧会显示一行“采集健康度”，用于判断采集是否完整：

- **轮询兜底**：Raw Input 没有投递、由物理键状态轮询补上的按键次数。典型来源是 PrtSc
  （Windows 只发送它的松开事件），以及被其它程序注册为全局热键的组合键（例如翻译工具的 Shift+Z）；
- **松键自愈**：纠正“丢失松开事件”的次数。没有这项校正时，某个键一旦卡在“按下中”，之后所有按下
  都会被当成按住不放的连发而不再计数；
- **轮询覆盖 / 心跳**：轮询可以观测到的键数量，以及轮询线程的采样次数。心跳应持续增长；
  若心跳停止增长，说明采集线程异常，请重启程序。

## 数据保存与迁移

- 数据保存在程序旁的 `Data` 目录；
- 完整移动程序文件夹即可迁移数据；
- 完整版与轻量版的数据格式相同，可以直接复制整个 `Data` 目录；
- 如果移动前启用了登录自动启动，请在新位置运行程序后，取消并重新勾选一次，以更新启动路径。

## 两种版本

- 完整版：内含 .NET 10 桌面运行时，无需安装其他环境；
- 轻量版：文件更小，需要电脑已安装 x64 `.NET 10 Desktop Runtime`。

## 游戏兼容性

如果游戏以管理员权限运行，请先从托盘完整退出 KeyStats，再尝试以管理员身份启动 KeyStats。部分采用独占输入或反作弊隔离的游戏可能不会向普通桌面程序提供输入事件。
